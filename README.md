# Account-Ai — страница профиля

Вёрстка страницы профиля пользователя на чистых **HTML, CSS и JavaScript** — без фреймворков, CDN и сборки.

**Демо:** https://leshashirokov.github.io/Account-Ai/

## Возможности

- Профиль: фото (или инициалы, если фото нет), фамилия, имя, отчество, должность, организация, телефон, e-mail, «О себе».
- Социальные сети с inline SVG-иконками: ВКонтакте, Telegram, GitHub, LinkedIn, личный сайт.
- Режим редактирования:
  - загрузка фото (JPG/PNG/WebP/GIF, до 5 МБ), обрезка до квадрата по центру и уменьшение до 512×512 через canvas, предпросмотр, удаление;
  - проверка полей с сообщениями под полями: ФИО (буквы, дефис, апостроф), телефон приводится к `+7XXXXXXXXXX`, формат e-mail;
  - ссылки только `http://`/`https://` с проверкой домена (vk.com/vk.ru, t.me, github.com, linkedin.com), для Telegram можно ввести `@username`;
  - сохранение/отмена, предупреждение о несохранённых изменениях, уведомления (toast).
- Хранение в `localStorage`, демо-профиль вымышленного человека при первом открытии, кнопка «Сбросить» с подтверждением.
- Экспорт и импорт профиля в JSON (с проверкой и санитизацией: лишние поля отбрасываются, некорректные данные отклоняются).
- Светлая/тёмная тема (учитывает системную настройку, выбор сохраняется).
- Безопасный вывод: только `textContent`/`setAttribute`, без `innerHTML`; внешние ссылки с `rel="noopener noreferrer nofollow"`; Content-Security-Policy.
- Адаптивность (две колонки на десктопе, одна на мобильных, без горизонтальной прокрутки от 320 px), доступность: работа с клавиатуры, ARIA-атрибуты, заметный фокус, `prefers-reduced-motion`.

## Структура

```
index.html          — разметка страницы (просмотр + форма редактирования)
css/style.css       — стили, темы, адаптивность
js/theme-init.js    — ранняя установка темы (без «вспышки»)
js/icons.js         — inline SVG-иконки
js/validation.js    — валидация, нормализация, санитизация
js/storage.js       — localStorage, демо-профиль, экспорт/импорт JSON
js/photo.js         — обработка фото через canvas
js/ui.js            — toast, диалог подтверждения, переключатель темы
js/render.js        — отрисовка профиля
js/editor.js        — форма редактирования
js/app.js           — точка входа
tests/              — тесты на jsdom
```

## Локальный запуск

Достаточно открыть `index.html` в браузере. Или запустить простой сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Тесты (нужен Node.js):

```bash
npm install
npm run check   # node --check для всех JS-файлов
npm test        # тесты валидации, хранения, импорта/экспорта, XSS, формы
```

## Ключи localStorage

| Ключ | Содержимое |
|------|------------|
| `account-ai.profile.v1` | `{ version, updatedAt, profile }` — сохранённый профиль (фото — data URL JPEG) |
| `account-ai.theme` | `light` или `dark` — выбранная тема |

## Ограничения

- Данные хранятся только в текущем браузере; синхронизации и сервера нет. Очистка данных сайта удаляет профиль.
- Объём `localStorage` ограничен (обычно ~5 МБ), поэтому фото сжимается до 512×512 JPEG.
- Фото обрезается по центру, ручного выбора области нет; прозрачный фон PNG становится белым, GIF — только первый кадр.
- Поддерживаются только российские номера телефона (+7). E-mail и домены — латиница/punycode (кириллические домены в e-mail не принимаются).
- Для VK/Telegram/GitHub/LinkedIn принимаются ссылки только на профиль (без вложенных путей).
